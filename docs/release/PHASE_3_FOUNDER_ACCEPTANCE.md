# PATHZY Phase 3 Founder Acceptance

Status: REQUIRED BEFORE RELEASE TAG

Use fictional test accounts only. Do not use real user data or production customer profiles.

## New French User

1. Open the public page.
2. Select French.
3. Create a new test account.
4. Complete Professional Identity.
5. Confirm autosave and persistence.
6. Review information.
7. Finish setup.
8. Start Employment Diagnosis.
9. Confirm questions are relevant and do not repeat known Identity facts.
10. Refresh during Diagnosis and confirm resume works.
11. Switch French to English to French and confirm answers remain.
12. Complete Diagnosis.
13. Review Diagnosis Results.
14. Confirm one clear primary action.
15. Confirm strengths and barriers are evidence-backed and supportive.
16. Open Home and confirm the same primary action.
17. Open Career Plan.
18. Start and complete one action.
19. Refresh, logout, close browser, login again.
20. Confirm Intelligence, Action History and Career Plan progress remain.
21. Edit a meaningful Identity field.
22. Confirm stale state and recomputation behaviour.

## Returning English User

1. Login as a completed test user.
2. Confirm Home opens directly.
3. Confirm English UI.
4. Confirm onboarding does not restart.
5. Confirm current intelligence loads.
6. Confirm completed actions do not return.
7. Confirm Career Plan progress.
8. Switch English to French to English.
9. Confirm no recomputation or data loss.
10. Logout/login and confirm persistence.

## Lower-Literacy User

Confirm short prompts, one question per screen, simple choices, visible progress, one primary action, simple Career Plan wording, respectful tone, mobile usability and no capability penalty.

## Immediate-Income User

Confirm urgent practical action appears while stable-employment and long-term career planning remain available. Confirm no unsafe, unlawful or one-size-fits-all recommendation appears.

## Diverse Employment Levels

Validate fictional profiles for cleaner, domestic worker, security candidate, retail worker, driver or warehouse worker, administrator, artisan, IT technician, graduate, professional, manager/executive and entrepreneur.

## Account Switching

1. Login User A.
2. Load Home, Intelligence and Career Plan.
3. Start an action.
4. Logout.
5. Login User B.
6. Confirm no User A data appears.
7. Logout.
8. Login User A.
9. Confirm User A progress remains.

Account switching is a release blocker if it fails.
