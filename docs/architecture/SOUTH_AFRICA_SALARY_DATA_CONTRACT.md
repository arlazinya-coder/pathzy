# South Africa Salary Data Contract

Implemented in:

`lib/employment-intelligence/country/adapters/south-africa/recruitment-conventions.ts`

The salary boundary supports:

- currency: ZAR
- role family
- job level
- province or region
- annual, monthly or hourly basis
- gross/net marker
- source
- effective date
- sample size
- confidence
- percentile bands
- unavailable state

Phase 3C contains no salary values.

Default salary state:

`UNAVAILABLE`
