# Employment Intelligence Staleness

Canonical stale reasons:

- IDENTITY_CHANGED
- DIAGNOSIS_CHANGED
- COUNTRY_CONTEXT_CHANGED
- ENGINE_VERSION_CHANGED
- ACTION_HISTORY_CHANGED
- EXTERNAL_CONTEXT_STALE
- MANUAL_REVIEW_REQUIRED
- UNKNOWN

Language, theme and presentation-only changes do not mark intelligence stale.

Stale means review or recompute is useful. It does not mean the previous result is deleted or invalid.
