# Employment Diagnosis Result Model

`EmploymentDiagnosisResult` contains:

- summary codes
- diagnosis status
- primary employment situation
- strongest signals
- major barriers
- practical constraints
- immediate needs
- work eligibility uncertainty
- digital access needs
- support needs
- preferred pathway signals
- evidence gaps
- unanswered important questions
- identity suggestions
- readiness-impact references
- country-context references
- confidence
- explanation facts
- diagnosis version
- generated timestamp

The result feeds Phase 3B deterministic Employment Intelligence. It is not a final Career Plan.
