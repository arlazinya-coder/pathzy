# Employment Readiness Model

Status: Phase 3A contract
Code: `lib/employment-intelligence/domain/readiness.ts`

1. Identity Readiness
2. Career Direction Readiness
3. Qualification Readiness
4. Experience Readiness
5. Skills Readiness
6. Evidence Readiness
7. Document Readiness
8. Opportunity Readiness
9. Application Readiness
10. Interview Readiness
11. Digital Access Readiness
12. Work Eligibility Readiness
13. Practical Access Readiness
14. Confidence and Support Readiness

## Bands

- `NOT_ASSESSED`: PATHZY has not assessed this dimension.
- `NEEDS_FOUNDATION`: Core information or support is needed before this dimension can guide action.
- `DEVELOPING`: The user has a useful starting point and needs focused strengthening.
- `READY_WITH_SUPPORT`: The user can move forward with targeted support or practical adjustments.
- `READY`: The user has enough confirmed information and preparation to proceed confidently.
- `STRONG`: The user has strong evidence, preparation, and clarity.

Forbidden readiness language: weak, poor, bad, unemployable.

## Overall readiness

Overall readiness is not a simple average unless a future methodology justifies it. Critical dependencies may cap a result. Unknown information reduces confidence, not human potential. A number may be shown only as secondary supporting detail.
