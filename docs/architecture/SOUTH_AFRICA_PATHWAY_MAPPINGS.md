# South Africa Pathway Mappings

Implemented in:

`lib/employment-intelligence/country/adapters/south-africa/pathway-context.ts`

The adapter maps every Phase 3A pathway code to:

- context relevance
- dependencies
- unavailable live-data warning
- confidence effect
- source requirements
- explanation keys

Covered pathways include:

- direct, entry-level, skilled and professional employment
- graduate programme
- internship
- learnership
- apprenticeship
- temporary, contract and part-time work
- informal or community work
- self-employment and micro-enterprise
- skills-first transition
- return to work
- career change
- qualification recognition
- bridging education
- licence or certificate
- public employment programme
- supported employment

Live programme availability and eligibility rules remain unavailable until sourced.
