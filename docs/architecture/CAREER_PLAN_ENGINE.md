# Career Plan Engine

The Career Plan engine lives in `career-plan-engine.ts`.

It generates a derived Career Plan from:

- Employment Intelligence profile context
- the selected primary and secondary actions
- pathway recommendations
- barriers and missing information
- support intensity
- immediate-income evidence
- action history and document state

Required horizons:

- TODAY
- THIS_WEEK
- THIS_MONTH
- NEXT_3_MONTHS
- LONGER_TERM

The user-facing name is Career Plan. The technical `/roadmap` route may continue to exist as a compatibility URL, but Roadmap is not the primary product label.
