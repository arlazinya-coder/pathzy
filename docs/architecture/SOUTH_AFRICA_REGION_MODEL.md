# South Africa Region Model

Implemented in:

`lib/employment-intelligence/country/adapters/south-africa/regions.ts`

Canonical province codes:

- EC
- FS
- GP
- KZN
- LP
- MP
- NC
- NW
- WC

Each province has:

- canonical code
- canonical English name
- English and French labels
- structural hub contract
- mobility context
- transport considerations
- remote-work availability state
- source IDs

No province-level demand, salary, commute, safety, or forecast claims are included.
