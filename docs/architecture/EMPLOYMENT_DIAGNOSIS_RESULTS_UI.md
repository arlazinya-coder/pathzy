# Employment Diagnosis Results UI

Diagnosis completion now triggers Phase 3F recomputation and routes to `/discovery/results`.

The results view answers:

- what PATHZY understood;
- what helps the user;
- what may block progress;
- what to do first;
- which plan step comes next;
- what remains uncertain.

The page does not display raw questionnaire answers as the primary result and does not mutate Professional Identity automatically.
