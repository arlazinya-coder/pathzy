# South Africa Source Registry

Implemented in:

`lib/employment-intelligence/country/adapters/south-africa/source-registry.ts`

Each source record supports:

- sourceId
- title
- authority
- sourceType
- jurisdiction
- URL or external reference
- retrievedAt
- effectiveFrom/effectiveTo
- lastReviewedAt
- nextReviewAt
- confidence
- topicsCovered
- notes
- status

Phase 3C includes structural internal context and placeholders for source-backed data that must remain unavailable until verified.
