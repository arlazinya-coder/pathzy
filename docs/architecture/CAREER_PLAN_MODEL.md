# Career Plan Model

Status: Phase 3A contract
Code: `lib/employment-intelligence/domain/career-plan.ts`

## User-facing language

Use `Career Plan` as the primary user-facing term. `Roadmap` is legacy language and must not become the Phase 3 primary label.

## Horizons

- `TODAY`
- `THIS_WEEK`
- `THIS_MONTH`
- `NEXT_3_MONTHS`
- `LONGER_TERM`

## Step states

- `NOT_STARTED`
- `IN_PROGRESS`
- `BLOCKED`
- `COMPLETED`
- `SKIPPED`

The Career Plan adapts to immediate income urgency, readiness, barriers, pathway, support intensity, country context, time, and resources.
