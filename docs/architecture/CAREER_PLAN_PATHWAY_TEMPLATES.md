# Career Plan Pathway Templates

Phase 3E uses one rules-based planner rather than separate engines per pathway.

Supported pathway adaptation includes:

- direct employment
- entry-level employment
- cleaner/service work
- security registration uncertainty
- retail/administrative pathway
- technical/project evidence
- skilled trade or artisan evidence
- graduate/internship route
- professional route
- career change
- return to work
- qualification recognition
- licence or certificate clarification
- immediate income
- self-employment and micro-enterprise
- skills-first transition
- generic non-South Africa context

Adapters may influence which actions rise or become blocked. They must not introduce live programme names or unstable claims in this phase.
