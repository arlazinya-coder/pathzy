# Career Plan UI

The Career Plan preview appears on Home and links to `/roadmap/career-plan`.

Plan progress comes from persisted Career Plan data that is refreshed from Action History. The UI does not duplicate progress state.

The full view groups steps by horizon:

- Today
- This week
- This month
- Next 3 months
- Longer-term

Users can start, complete or skip supported actions through the same action component used on Home.
