# South Africa Qualification Context

Implemented in:

`lib/employment-intelligence/country/adapters/south-africa/qualification-framework.ts`

Phase 3C supports contracts for:

- school-level education
- matric completed
- matric incomplete
- TVET
- certificate
- diploma
- degree
- postgraduate qualification
- occupational qualification
- trade qualification
- foreign qualification
- incomplete qualification

## Rules

- No NQF level is assigned without reliable mapping evidence.
- Foreign qualifications create recognition uncertainty where relevant.
- No degree and no matric are not treated as inability.
- Informal and occupational learning remain relevant.
- Recognition state remains evidence-aware.
